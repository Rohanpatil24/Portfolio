1. Server-Side Framework & ORM Models

Python // Django // Relational Schema

The backbone of the application runs on Django, leveraging its robust Model-View-Template (MVT) architecture for deterministic routing, CSRF protection, and media pipeline segregation.

Relational schema design via Django ORM decouples static view code from persistent data:

  • PersonalInfo: Core identity, biography, and CV assets.
  • Experience & Project: Chronologies sorted by explicit ordering keys.
  • Certification: Secure credential records with @property is_pdf document inspection.
  • SiteTraffic & ContactMessage: Analytics tracking daily page encounters and encrypted contact queries.
// core/models.py snippet
class Certification(models.Model):
    title = models.CharField(max_length=150)
    institution = models.CharField(max_length=150)
    date_completed = models.CharField(max_length=50)
    file = models.FileField(upload_to='certificates/')

    @property
    def is_pdf(self):
        return bool(self.file and self.file.name.lower().endswith('.pdf'))

2. WebGL 3D Render Engine

Three.js // Shaders // Real-time Parallax

Interactive visual computing is realized using Three.js running over HTML5 WebGL context without relying on heavy external asset bundles:

  • Volumetric Particle Matrix: A THREE.Points system containing 700 custom spatial coordinates floating across an unbounded field, rotated on continuous delta loops.
  • Quantum Orbitals: Parametric THREE.TorusGeometry rings with wireframe alpha materials rotating asynchronously across the X and Y axes.
  • Cursor Parallax Tracking: Normalized mouse vectors continuously interpolate the camera orientation via lerping algorithms to create depth without jarring transitions.

3. Kinematic Systems & SPA Navigation

Vanilla ES6+ // HTML5 History API // Sub-Pixel Engine

Sub-Pixel Auto-Glide

A delta-time requestAnimationFrame engine eliminating frame-by-frame rounding jitter. Features 1x/2x/3x velocity scaling, a 3-second restart buffer, and instant lockout upon manual wheel detection.

Clean SPA Routing

Integrates History.pushState and replaceState to banish unsightly hash fragments (#projects) while keeping active scrollspy navbar states synchronized.

Security Enclave Viewers

Modal dialogs preventing right-click extraction on certificates, dynamic sandbox iframes for PDF streams, and anti-leak focus-loss privacy filters.

4. Design Tokens & Glassmorphism

Tailwind CSS // Specular Highlighting // Phosphor Icons

The interface employs modern glassmorphism characterized by high-radius backdrop blur filters (backdrop-filter: blur(28px)), semi-transparent RGBA color blends, and interior specular borders simulating glass edges.

Both Dark and Light themes are engineered as first-class citizens. Theme states are bound to local storage and hydrated before DOM render to prevent theme flashing during navigation.
